# Changelog

All notable changes to Planet Lib will be documented here.

## 0.1.0-alpha.1

Initial development milestone for Fabric and Minecraft Java 1.21.11.

- Mod Registry for immutable snapshots of Fabric-loaded mod metadata.
- Typed JSON Configuration API with explicit persistence and malformed-file protection.
- Feature Registry and deterministic Feature Priority Manager.
- Optional, version-negotiated Planet Essentials bridge.
- Explicit Compatibility API.
- Version and Capability Detection.
- Bounded in-memory Diagnostics API.
- Namespaced Resource API for metadata registration and lookup.
- Executor-neutral Task Utilities with observable lifecycle and queued cancellation.
- Optional Input API for logical action metadata, without synthetic input or automatic hooks.

This is an alpha development build. Runtime validation in Minecraft and a public release license are still pending.
